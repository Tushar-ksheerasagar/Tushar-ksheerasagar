### 📌 Featured Projects

#### 🧠 [AI Portfolio Analyzer](https://github.com/Tushar-ksheerasagar)
`FastAPI` `Python` `PostgreSQL` `Mistral AI` `LangChain` `Chart.js` `pytest`

A full-stack investment analytics SPA for Indian equity markets. Built a custom **quant math engine** computing Sharpe ratio, Beta, volatility, max drawdown, and HHI sector concentration. Integrated **Mistral AI via LangChain** for structured portfolio health diagnostics with offline-state fallback guardrails. Secured with **HttpOnly JWT + bcrypt**, optimized with an in-memory TTL cache for yfinance data, and validated via an automated **pytest suite** with SQLite overrides.

---

#### 🌐 [Mini-RAFT Distributed Drawing Board](https://github.com/Tushar-ksheerasagar)
`Python` `FastAPI` `Node.js` `Express` `WebSockets` `Docker` `Docker Compose` `pytest`

Implemented a **custom RAFT consensus protocol** from scratch — randomized leader election, append-only log replication, and state consistency across cluster nodes. Built a **Node.js WebSocket Gateway** as an intelligent reverse proxy for active-leader detection and client failover. Simulated **split-brain partitions and server crashes** via Docker Compose; added SHA-256 block hashing for log integrity and automated pytest integration suites for failover correctness.

---

#### 🏨 [Hostel Visitor Management System](https://github.com/Tushar-ksheerasagar)
`Java` `Spring Boot` `Thymeleaf` `Spring Data JPA` `MySQL`

Full-stack visitor management platform with ID verification, student approval/rejection workflows, and entry/exit tracking. Applied **OOAD principles and GoF design patterns** (Factory, Adapter, Observer, Singleton) within an MVC architecture for a modular, scalable solution.
